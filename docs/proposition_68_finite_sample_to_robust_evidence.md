# Proposition 68: finite-sample physical uncertainty to robust downstream evidence

P68 composes the P67 finite-sample boundary record with the P62/P66 robust evidence envelope.

For a residual innovation count r, P67 supplies a retained physical-boundary set R_r whenever the Proposition 47 covariance radius lies inside the current perturbative regime. Given valid path-specific downstream e-values E_p, define

E_rob(r) = inf over p in R_r of E_p.

This creates the first explicit finite-sample information-to-evidence interface in the repository.

If P67 has not entered its perturbative regime, P68 returns no robust evidence conclusion rather than treating an unavailable physical certificate as if all paths or one selected path were valid.

If a weak-evidence competitor remains in R_r, it remains binding even when the selected path has strong evidence. Only certified changes to R_r, or stronger evidence for the competitor itself, can change that worst-case envelope.

The probability and data-separation assumptions are inherited from the upstream covariance event and the path-specific e-value construction. P68 is deterministic conditional on those valid inputs and spends no additional probability budget.

Scientific boundary: this proposition concerns robustness to uncertainty in a learned physical representation. It does not identify any retained boundary with consciousness or interpret an e-value as a posterior probability.
