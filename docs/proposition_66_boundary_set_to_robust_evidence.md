# Proposition 66: Boundary-set contraction and robust downstream evidence

## Question

P58, P64, and P63 determine which physical world-tubes remain compatible with the declared measurement uncertainty. P62 says downstream evidence must survive every retained physical alternative. P66 makes that composition explicit.

Let R be the retained boundary set. For each p in R, suppose Research II supplies a nonnegative e-value E_p that is valid for the downstream null associated with p, under the declared data-separation or simultaneous-validity conditions.

Define

E_rob(R) = inf_{p in R} E_p.

This is the P62 robust e-value for the union null over R.

## Result 1: contraction monotonicity

If R_1 is a subset of R_2, then

E_rob(R_1) >= E_rob(R_2).

Therefore certified removal of physical alternatives can never weaken the worst-case downstream e-evidence.

This is a deterministic statement about the evidence envelope. It does not by itself justify removing any path; that justification must come from P63 and its upstream interval event.

## Result 2: unresolved competitors remain binding

A large e-value on the selected path is insufficient whenever another retained path has weak evidence. If p_selected has E=30 but a retained competitor has E=2, then E_rob=2. The conclusion may cross a threshold only after the competitor is validly excluded or its own downstream evidence becomes strong enough.

## End-to-end interpretation

The combined chain is now

measurement uncertainty -> P58 score radii -> P64 action intervals -> P63 retained physical set -> P66/P62 robust downstream evidence.

This gives measurement precision a scientifically relevant endpoint. Better precision matters only when it validly changes the retained physical set or when the remaining alternatives themselves support the downstream conclusion.

## Scientific boundary

P66 does not turn an e-value into a probability that a hypothesis is true. A threshold such as 1/alpha is an evidence decision rule under the declared e-value framework. The validity of each path-specific e-value and the construction of the retained set must be established separately.

P66 also does not identify a retained subsystem with consciousness or an experiential state.
