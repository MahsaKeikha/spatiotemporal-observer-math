# Closest-method comparison protocol

This page records the **comparison questions** Research I must survive before any broad novelty statement is made. It is intentionally conservative. Neighboring methods can share important ingredients with Research I without solving the same inference problem.

The comparison target is the complete Research I object:

\[
\mathcal W=(S_0,\ldots,S_{T-1}),\qquad S_t\subseteq\{1,\ldots,n\},
\]

where coordinate membership itself can change with time and the selected path is determined by a global objective containing local dynamical evidence, cross-time transport, and continuity.

## Neighboring method families

### Multiple-model and interacting-multiple-model estimation

Classical multiple-model and IMM methods represent changing behavior through a finite collection of candidate dynamical models and infer/model-average a discrete mode. Variable-structure variants can adapt the active model set. This is an important neighbor because both frameworks perform inference under structural change.

The comparison question is therefore not "does IMM handle structural change?" It does. The narrower question is whether the latent object is a **combinatorial moving coordinate subset** whose membership defines the candidate subsystem, and whether the method supplies the same path-level recovery, symmetry-aware identifiability, and covariance-to-path certification chain.

### Switching and hybrid system identification

Switching-system methods infer mode sequences and/or mode-dependent dynamics. They are direct neighbors of the world-tube path formulation. Research I must distinguish a prescribed finite mode alphabet from a candidate family generated by coordinate subsets, and must compare its global path objective and recovery certificate against mode-sequence inference rather than describing switching methods as unrelated.

### Time-varying topology and network inference

Dynamic-network methods can infer changing edges, adjacency matrices, or dependency graphs from time-indexed observations. These methods are especially important because they already treat a changing structural object rather than a fixed mode.

Research I must therefore explain why inference of a moving subsystem boundary is not simply topology tracking. The relevant distinction, if supported, is that Research I selects a time-indexed **subset boundary** using internal predictive integration, environmental insulation, persistence, and cross-time transport, rather than estimating the complete edge-weight matrix or graph.

### Dynamic support estimation

Sparse and dynamic-support methods infer changing active coordinates. This is potentially the closest conceptual neighbor to the moving-subset object. Any novelty statement must compare the observation model, temporal coupling, candidate score, recovery target, and finite-sample guarantee rather than relying on different application terminology.

### Change-point and regime inference

Change-point methods localize times at which a data-generating law changes. Research I allows the selected subset to evolve at every time index and therefore should be compared on whether it estimates change times, regime labels, coordinate membership, or a complete structured path.

## Comparison matrix to maintain

For each closest paper, fill this table from the paper itself.

| Field | Question |
| --- | --- |
| Latent object | mode, graph, support, partition, subset boundary, parameters, or combination? |
| Candidate space | fixed finite library, learned models, all subsets of fixed size, sparse graph family, other? |
| Structural motion | can coordinate membership change with time? |
| Temporal coupling | Markov prior, fused penalty, continuity cost, transport evidence, none? |
| Local evidence | likelihood, residual, sparsity objective, information score, other? |
| Global inference | filtering, smoothing, Viterbi/DP, convex program, greedy, other? |
| Recovery statement | what exactly is guaranteed? |
| Identifiability | are observational symmetries/equivalent labels treated? |
| Finite sample | is there an explicit nonasymptotic certificate? |
| Dependence | are temporally correlated/irregular measurements covered? |
| Computation | complexity and scaling assumptions |
| Validation | synthetic, physical experiment, external data? |

## Current defensible distinction

The repository supports the following **descriptive** distinction:

> Research I infers a globally coupled path of changing coordinate subsets from stochastic dynamics and explicitly connects the path decision to recovery margins, observational identifiability, covariance uncertainty, temporal calibration, and observer-scale certification.

This is stronger and safer than claiming that moving structure itself is new. Multiple-model estimation, switching systems, dynamic supports, and time-varying network inference all predate this project.

## Priority rule

Do not write "first," "unique," "unprecedented," or "no prior method" unless the closest-literature audit directly supports that exact statement. Prefer a feature-by-feature comparison that lets the reader see the difference.

## Evidence rule

Every row eventually added to a literature-comparison table must be checked against the primary publication. Search snippets, abstracts, review papers, and repository notes are discovery aids, not sufficient evidence for detailed absence claims.

## Research consequence

If a neighboring method already contains one of the claimed distinctive features, Research I should become stronger scientifically rather than rhetorically: narrow the contribution, prove a sharper result, add the neighboring method as a baseline, or identify a combination of guarantees that is actually supported by the record.
