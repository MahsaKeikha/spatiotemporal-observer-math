## Exact irregular-grid transition law

For physical timestamps

\[
t_1<\cdots<t_N
\]

and relaxation time \(\tau>0\), define

\[
\Delta_i=t_{i+1}-t_i,
\qquad
\alpha_i=e^{-\Delta_i/\tau}.
\]

The exponential covariance

\[
R_\tau(i,j)=e^{-|t_i-t_j|/\tau}
\]

is generated exactly by

\[
X_{i+1}
=
\alpha_i X_i
+
\sqrt{1-\alpha_i^2}\,\varepsilon_i,
\]

where the innovation variables are independent standard Gaussians.

For \(i<j\),

\[
\operatorname{Cov}(X_i,X_j)
=
\prod_{k=i}^{j-1}\alpha_k
=
e^{-(t_j-t_i)/\tau}.
\]

Thus an irregular record does not need an invented integer lag. Each observed time gap receives the transition coefficient implied by the same physical \(\tau\).

## Exact temporal whitening

The release constructs a lower-bidiagonal whitening matrix \(W_\tau\) satisfying

\[
\boxed{
W_\tau R_\tau W_\tau^\mathsf T=I
}.
\]

For a separable multivariate Gaussian record with covariance

\[
R_\tau\otimes\Sigma,
\]

temporal whitening gives

\[
\boxed{
(W_\tau\otimes I)
(R_\tau\otimes\Sigma)
(W_\tau^\mathsf T\otimes I)
=I\otimes\Sigma
}.
\]

Under the declared model, the transformed temporal rows are therefore independent and retain the same spatial covariance.

## Exact sparse precision matrix

The covariance inverse is

\[
R_\tau^{-1}=W_\tau^\mathsf T W_\tau.
\]

It is exactly tridiagonal. The dense long-range covariance is generated by local temporal propagation, while the Gaussian conditional-dependence graph contains only adjacent timestamp edges.

For an \(N\)-sample scalar record, the exact precision matrix has at most

\[
3N-2
\]

nonzero entries instead of \(N^2\).

## Exact determinant factorization

The determinant is also local:

\[
\boxed{
\det(R_\tau)
=
\prod_{i=1}^{N-1}(1-\alpha_i^2)
}
\]

and

\[
\boxed{
\log\det(R_\tau)
=
\sum_{i=1}^{N-1}\log(1-\alpha_i^2)
}.
\]

This means the exact Gaussian likelihood geometry of the temporal kernel can be evaluated from adjacent time gaps without a dense covariance inversion.

## Missing-sample semigroup

If an intermediate timestamp is removed, local transitions compose exactly:

\[
\alpha_{13}=\alpha_{12}\alpha_{23}.
\]

The innovation variances compose consistently as well:

\[
\alpha_{23}^2(1-\alpha_{12}^2)
+
(1-\alpha_{23}^2)
=
1-\alpha_{13}^2.
\]

Missing observations therefore alter the observed local step but do not require a new physical relaxation time.
