# Contributing

This repository is an early research project. Contributions should preserve the
distinction between established results, new definitions, numerical findings,
and conjectures.

For mathematical changes:

- state all assumptions
- include a derivation or proof where possible
- add a counterexample or null model
- identify related prior work

For code changes:

- add tests for numerical and mathematical invariants
- keep experiments deterministic by setting random seeds
- generate each reported result from a versioned script
- avoid language suggesting that the score detects phenomenal consciousness
